P(ersistence)D(iagram)VIEW(ver)

More information can be found by hoovering the mouse over
the buttons in the toolbar (close this window first).

Navigation :

  • Left-click: zoom in
  • Right-click: zoom out
  • Middle-click: show coordinates
  • Middle-click + drag: pan
  • Left-click + drag: zoom in window
  • Left+Right-click: auto fit view
  • Ctrl+Left-click+drag: select persistence threshold

Choosing the threshold :

  • Ctrl+Left-drag: the magenta line follows the cursor, release to fix it
  • Set button: the line follows the cursor until you toggle Set off
  • DONE: quit and return the threshold to 'mse'
  • Keys button: show/hide the controls legend drawn on the plot
